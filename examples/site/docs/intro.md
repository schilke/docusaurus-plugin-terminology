# Terminology plugin demo

This site is the living regression test for `docusaurus-plugin-terminology`.

It demonstrates the `0.2.0` layout:

- Term definitions live in a **top-level `terms/` directory** and are rendered
  as standalone pages under [`/terms/`](/terms/) (no docs sidebar entry).
- A [glossary page](/docs/glossary) is generated from the term definitions.
- Links to terms anywhere in your Markdown are automatically enhanced with a
  tooltip, e.g. [AI](/terms/ai), [CSS](/terms/css) or [FTP](/terms/ftp).

See [Sample page](/docs/sample) for inline examples.
