This page shows inline links to terms that the plugin enhances with tooltips.

- [AI](/terms/ai) — artificial intelligence.
- [CSS](/terms/css) — cascading style sheets.
- [FTP](/terms/ftp) — file transfer protocol.
- [HTML](/terms/html) — hypertext markup language.

Hover (or focus) a link to see the tooltip. The link itself still navigates to
the dedicated term page.

## Non-term links are untouched

This [external link](https://docusaurus.io/) and this
[internal docs link](/docs/glossary) behave exactly like normal Docusaurus
links.
